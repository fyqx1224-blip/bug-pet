# 桌面隐翅虫宠物 Bug Pet

一只会在你桌面上闲逛、起降、振翅的小虫子。翅膀任何时候都能看见，落地会"喘口气"，你拿鼠标凑过去它会被吓飞。

## ⬇️ 下载（免安装，开箱即玩）

[**⬇️ 下载 `bug-pet-v1.0-coop-pack.zip`（桌面隐翅虫壁纸联机包，约 40 MB）**](https://github.com/fyqx1224-blip/bug-pet/releases/latest)

解压后双击 `双击我-开始玩.bat` 就够了：自动备份你当前的壁纸 → 换成「隐翅虫饲养房间」壁纸 → 虫子出现在桌面上。**不需要安装 Python**。想换回原来的壁纸，双击 `恢复我原来的壁纸.bat`。更多玩法见压缩包内的 `README.txt`。

## 🚀 怎么放桌面上（源码运行）

**已经放好了一个**：直接到桌面上双击 **`桌面隐翅虫.bat`** 即可召唤虫子。** 之后想停掉它，再右键虫子本体选"退出"。

> 双击 .bat 不会弹黑窗（已用 `start` 隐藏）；第一次运行若杀毒软件警告，** 添加信任即可**。

### 手动启动

```bash
pip install -r requirements.txt
python src/bug_pet.py
```

或双击项目里的 `start.bat`。

## 🐞 怎么玩

- **左键按住**：抓虫子随便拖
- **松开 / 双击**：让它自己接着逛
- **鼠标凑近**：自动吓飞
- **右键虫子**：打开菜单——飞一下 / 去吃饭 / 去睡觉 / 去训练 / **缩小虫子**（再右键可继续缩小，最小 30%；缩小后菜单里会出现"恢复原本大小"，大小会自动记住）/ **后代图鉴**（查看已开出的体色收集进度）/ 联机… 
- **Esc**：退出（或右键菜单 → 退出）

## 🎁 后代盲盒

交配产下的虫卵在**孵化瞬间**随机开出后代的体色 / 纹样 / 体型：

- **体色 9 款**：经典红褐 / 暗赭 / 土黄 / 蓝钢 / 墨绿 / 紫罗兰 / 橙金 / **白化** / **黑金**（隐藏款各约千分之几）
- **纹样 4 种**：无纹 / 鞘翅斑点 / 深横带 / 异色头
- **体型 5 档**：0.85 – 1.2 倍，纯外观
- 稀有度（普通 75% / 少见 18% / 稀有 6% / 隐藏 1%）只加快恢复速度（最高 ×1.35），数值上限和衰减都不变——更好养，而不是更强
- 开盒演出约 3 秒（摇晃 → 裂壳 → 稀有度光芒变色 → 名称横幅），**点击即可跳过**，演出期间发育时钟暂停
- 虫卵在开盒前看不出里面是什么；右键虫子 → **后代图鉴** 查看 9 格收集进度

## 🎨 状态机

| 状态 | 视觉 | 行为 |
|---|---|---|
| `landed` | 带翅行走帧 + 落地阴影 + 轻微呼吸 | 落地休息 0.7–2.3 秒后决定下一步 |
| `walking` | 带翅行走帧 | 朝目标点缓步走过去（速度 ~1.5 px/帧） |
| `flying` | 4 帧振翅循环 + 6° 微倾 + 贝塞尔曲线 | 二次贝塞尔飞行轨迹，落点偏屏幕中下部 |
| `dragging` | 当前帧暂停 | 拖动时冻结状态机 |

## 🛠 技术栈

- **PyQt5** — 透明无边框置顶窗口（`WA_TranslucentBackground` + `FramelessWindowHint` + `WindowStaysOnTopHint` + `Tool`）
- **Pillow** — 透明 PNG 精灵图镜像、缩放、ICO 转换
- **websockets** — 跨电脑联机中继（可选，离线模式无需安装）
- 纯 Python 标准库做贝塞尔插值与状态机调度

## 🌐 跨电脑联机（与同事一起玩）

需要双方电脑都装 **Tailscale**（免费）并登录同一账号。

**主机（你）**：
```bash
start_relay_host.bat
```
自动探测本机 Tailscale IP → 启动中继（`dist_relay\隐翅虫中继.exe`，无需 Python）→ 再启动宠物。
首次运行会弹**一次** UAC 授权放行防火墙端口 8765（规则名 `BugPetRelay8765`，只弹一次），
不授权同事连不进来。弹出的黑色中继窗口要保持开着。

**同事（访客）**：
把打好的联机包 zip（如 `桌面联.zip`）发给她，解压后**双击 `双击我-开始玩.bat`**——
不用装 Python，不用装别的东西。

**双方**：右键虫子 → **联机：加入房间** → 输入同一个房间码（如 `ROOM-123`）→
对方屏幕上就会出现你的虫。三个状态栏喂满后可以 **联机：邀请交配**，动画同步，回窝各自产卵。
虫卵经 卵期 → 孵化后期 → 幼年期 → 成长期 → 成年期 慢慢长大，关机不丢进度；
孵化瞬间会开出随机的后代体色 / 纹样 / 体型（见上方「后代盲盒」）。
中途掉线会自动重连（约每 3 秒重试），屏幕上会有连接状态提示。

**房主 Tailscale IP 变了怎么办**：
用记事本打开联机包里的 `relay.txt`，改成新地址 `ws://新IP:8765` 保存，重开 exe；
或在"加入房间"对话框里直接粘贴完整 `ws://` 地址。
